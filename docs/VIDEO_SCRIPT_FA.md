# متن ویدیوی دمو (حدود ۴ دقیقه)

لحن: خودمونی و گفتاری، مثل توضیح دادن به یه همکار. عددها همون عددهای کد و مستنداته. وعدهۀ سود نمی‌دیم. طبق صورت چالش، لازم نیست کد نشون بدیم؛ خروجی مهمه.

## نسخهۀ ۴ دقیقه‌ای

| زمان | تصویر روی صفحه | متن گوینده |
|---|---|---|
| ۰:۰۰ تا ۰:۲۵ | نمودار اول `docs/OVERVIEW.md` | سلام. ما یه ربات معامله‌گر خودکار برای چالش والکس ساختیم. فقط اسپات و فقط خرید، با پنج میلیون تومن سرمایه، و آخر کار همه‌چی باید تبدیل به تومن بشه. تصمیم و ثبت سفارش دست کده. هوش مصنوعی فقط نظارت می‌کنه: می‌تونه یه معامله رو رد کنه یا کوچیک‌ترش کنه، ولی خودش هیچ معامله‌ای باز نمی‌کنه. |
| ۰:۲۵ تا ۱:۱۵ | داشبورد حالت دمو (`bun run dashboard --demo`)، نمودار یه ستاپ با برچسب‌های جارو، تأیید، شکاف، ورود، حدضرر، هدف | استراتژی یه نسخه‌ی ساده از آی‌سی‌تیه. زیر هر کف قیمتی کلی حدضرر جمع شده. گاهی قیمت یه لحظه می‌ره پایین‌تر، همه‌ی اونا رو جارو می‌کنه و برمی‌گرده. ما همین لحظه رو می‌پاییم. اگه بعدش یه کندل قوی قیمت رو ببره بالا، یعنی احتمالاً جهت عوض شده. بعد صبر می‌کنیم قیمت یه کم برگرده عقب، جایی که خیلی تند ازش رد شده بود، و همون‌جا با سفارش حدی می‌خریم. حدضرر زیر همون کفه و هدف، سقف قبلیه. |
| ۱:۱۵ تا ۱:۴۰ | جدول اندازه‌ی موقعیت در `docs/RISK.md` | کارمزد رفت‌وبرگشت حدود نیم درصده، پس اگه بعد از کارمزد چیزی نمونه، ربات وارد نمی‌شه. نتیجه‌ش اینه که معامله‌ها کمه و ما اینو قایم نمی‌کنیم. حجم هر معامله هم از حدضرر درمیاد: اگه حدضرر بخوره، دقیقاً یک درصد از حساب کم می‌شه. مثلاً با حدضرر دو درصد، حدود ۳۸ درصد سرمایه وارد می‌شه. بیشتر از دو موقعیت باز هم نداریم. |
| ۱:۴۰ تا ۲:۰۰ | داشبورد دمو با سناریوی توقف، بعد ترمینال: `touch STOP` | یه گارد ریسک هم داریم. اگه حساب ۱۲ درصد از اوج روز افت کنه، تا فردا ورود تازه نداریم. سه ضرر پشت‌هم نیم ساعت مکث می‌ده. و با یه فایل به اسم استاپ یا دکمه‌ی داشبورد، همه‌چی فوری می‌ایسته. |
| ۲:۰۰ تا ۲:۳۵ | یه خط لاگ `ai.verdict` یا پنل هوش مصنوعی داشبورد | هوش مصنوعی هم این‌جوری کار می‌کنه: کد که ستاپ رو پیدا کرد، یه عامل هوشمند ستاپ و خبرهای روز رو نگاه می‌کنه، از کوین‌دسک و کوین‌تلگراف تا شاخص ترس و طمع. جوابش یکی از سه‌تاست: تأیید، رد یا کوچیک‌کردن، با دلیلش توی لاگ. اگه مدل جواب نده، بعد از ۱۲ ثانیه حکم پیش‌فرض اعمال می‌شه. سفارش رو هم کد می‌ذاره، چون باید سریع و قابل بازبینی باشه. |
| ۲:۳۵ تا ۳:۱۰ | ترمینال: خلاصه‌ی `bun run backtest --strategy ict --symbols auto --days 7`، بعد جدول `docs/RESEARCH.md` | سه جور تست داریم: بک‌تست روی داده‌ی قدیمی، تست سایه روی بازار زنده با سفارش مجازی، و اجرای خشک که سفارش رو چک و ثبت می‌کنه ولی نمی‌فرسته. نتیجه‌ی بک‌تست هفت‌روزه رو صادقانه بگم: حدود یک درصد بازده، با افت یک‌درصدی و فقط دو معامله‌ی بسته‌شده. این نمونه خیلی کوچیکه و نشونه‌ی سود آینده نیست. |
| ۳:۱۰ تا ۳:۴۰ | داشبورد دمو و بعد گرافانا | این داشبوردمونه و داده‌هاش نمایشیه. ارزش حساب، ریسک فعلی، موقعیت‌های باز، ستاپ‌های رد و قبول‌شده با دلیل و حکم هوش مصنوعی رو می‌بینین. ربات متریک پرومتئوس هم می‌ده و تو گرافانا ده تا هشدار داریم، مثلاً قطع ضربان ربات یا توقف گارد. |
| ۳:۴۰ تا ۴:۱۰ | ترمینال: `bun run pullout`، بعد README | آخر اجرا، ۴۵ دقیقه مونده ورودها بسته می‌شه و ۱۵ دقیقه مونده همه‌ی سفارش‌ها لغو و هر کوین به تومن فروخته می‌شه. معامله‌ی دستی نداریم، فقط اسپات و یه حساب، و حجم مصنوعی هم نمی‌سازیم. داورا می‌تونن همه‌چی رو دوباره اجرا کنن، دستورها تو ریدمی هست. ممنون. |

## نسخهۀ ۶۰ ثانیه‌ای

| زمان | تصویر روی صفحه | متن گوینده |
|---|---|---|
| ۰:۰۰ تا ۰:۱۵ | نمودار اول `docs/OVERVIEW.md` | سلام. این یه ربات معامله‌گر خودکار برای چالش والکسه، فقط اسپات و فقط خرید. کد تصمیم می‌گیره و سفارش می‌ذاره. هوش مصنوعی فقط می‌تونه معامله رو رد یا کوچیک کنه و دلیلش رو بنویسه. |
| ۰:۱۵ تا ۰:۳۵ | داشبورد دمو با نمودار یه ستاپ | قیمت یه کف رو جارو می‌کنه، با یه کندل قوی برمی‌گرده و ما با سفارش حدی می‌خریم. هر معامله یک درصد سرمایه رو ریسک می‌کنه و کارمزد تو حساب هست، برای همین معامله‌ها کمه. |
| ۰:۳۵ تا ۰:۵۰ | خلاصه‌ی بک‌تست و `docs/RESEARCH.md` | بک‌تست هفت‌روزه حدود یک درصد بازده داشت، با دو معامله‌ی بسته‌شده. نمونه کوچیکه و نشونه‌ی سود آینده نیست. گارد ریسک و فایل استاپ هم ورود تازه رو می‌بندن. |
| ۰:۵۰ تا ۱:۰۰ | بخش «شروع سریع» در README | آخر اجرا همه‌چی به تومن فروخته می‌شه. دستورهای اجرای دوباره تو ریدمیه. ممنون. |

## نکات ضبط

- قبل از ضبط `bun run test` رو بزن که سبز بودنش تو ترمینال دیده بشه. قلم ترمینال رو بزرگ کن.
- داشبورد دمو ساختگیه. تو همون صحنه بگو داده‌ها نمایشیه. برای نمایش واقعی، لاگ یه بک‌تست رو با `bun run dashboard --replay logs/<فایل>.jsonl --speed 20` پخش کن.
- برای گرافانا، پیش از ضبط `docker compose -f ops/docker-compose.yml up -d` رو بزن و ربات رو با `bun run live --paper --run-end <زمان>` روشن بذار که نمودارها خالی نباشه.
- کلید API و `.env` نباید رو صفحه دیده بشه.
- اگه اجرای واقعی تموم شده، عددهای بک‌تست رو با ارزش نهایی حساب و بازده خالص واقعی عوض کن و همون‌قدر صادقانه بگو.
- متن گوینده حدود ۵۵۰ کلمه‌ست و با سرعت عادی نزدیک چهار دقیقه می‌شه. اگه پنج دقیقه می‌خوای، روی صحنهۀ داشبورد بیشتر بمون.
